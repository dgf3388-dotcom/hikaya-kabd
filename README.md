# حكاية كبدة والسجق

موقع مطعم **حكاية كبدة والسجق** — موقع تعريفي احترافي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يفتح على `http://localhost:8080`

## البناء

```bash
npm run build
```
